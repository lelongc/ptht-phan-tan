# P1.1 Chuẩn bị tài nguyên (theo plan)

Mục tiêu: cài đủ công cụ, tạo/clone repo, chuẩn bị file demo, lấy khóa sandbox/AWS để sẵn sàng bước P1.2.

## 1) Cài công cụ bắt buộc (Ubuntu 22/24)
```bash
sudo apt update
sudo apt install -y openjdk-17-jdk maven git unzip

# Docker + Compose
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
sudo usermod -aG docker "$USER"
newgrp docker

# Docker Compose v2 có sẵn: dùng lệnh `docker compose`

# AWS CLI v2
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"
unzip awscliv2.zip
sudo ./aws/install
aws --version
```

Kiểm tra nhanh:
```bash
java -version
mvn -v
docker -v
docker compose version
git --version
```

## 2) Tạo hoặc clone repo
```bash
git clone https://github.com/lelongc/ebook-store.git
cd ebook-store
```
Nếu chưa có repo riêng, tạo trên GitHub rồi thay URL cho phù hợp.

## 3) Chuẩn bị tài nguyên demo (để seed DB và test UI)
```bash
mkdir -p database/seed_files/ebooks database/seed_files/covers
# Sao chép 3-5 file PDF công khai vào database/seed_files/ebooks/
# Sao chép 5 ảnh bìa (png/jpg) vào database/seed_files/covers/
```

## 4) Đăng ký sandbox/payment + AWS
- PayPal Sandbox: tạo app, lấy `PAYPAL_CLIENT_ID`, `PAYPAL_CLIENT_SECRET` (mode sandbox).
- VietQR: dùng QR động qua URL `https://img.vietqr.io/image/{bank}-{account}-compact2.jpg?amount={amount}&addInfo={info}&accountName={name}` (không cần API key). Cần biết `bank` (mã bank hoặc bin) + `account` + `accountName`.
- AWS: tạo IAM user (không dùng root) với quyền S3/RDS/SES (dev) và tải Access Key/Secret.

Kiểm tra AWS CLI hoạt động:
```bash
aws sts get-caller-identity
```

## 5) Tạo file biến môi trường (local, không commit)
Tạo `.env.local` ở thư mục gốc repo:
```
PAYPAL_CLIENT_ID=your_sandbox_client_id
PAYPAL_CLIENT_SECRET=your_sandbox_client_secret
AWS_ACCESS_KEY=your_aws_access_key
AWS_SECRET_KEY=your_aws_secret_key
# VietQR không cần API key; cần cấu hình bank/account/accountName trong app
```
