# P1.3.3 Repositories (JPA)

Mục tiêu: tạo các interface JpaRepository cho entities và các query cơ bản hay dùng (find by status, email, secretCode, token...).

## 1) Chuẩn bị
Đảm bảo đã có entities trong `src/main/java/com/ebook/entity/` như bước P1.3.2.

## 2) Tạo package repository
`src/main/java/com/ebook/repository/`

## 3) UserRepository
`src/main/java/com/ebook/repository/UserRepository.java`
```java
public interface UserRepository extends JpaRepository<User, Long> {
    Optional<User> findByEmail(String email);
    boolean existsByEmail(String email);

    @Query("select u from User u where u.status = :status")
    List<User> findByStatus(@Param("status") UserStatus status);
}
```

## 4) EbookRepository
`src/main/java/com/ebook/repository/EbookRepository.java`

public interface EbookRepository extends JpaRepository<Ebook, Long>, JpaSpecificationExecutor<Ebook> {
    Page<Ebook> findByStatus(EbookStatus status, Pageable pageable);

    @Query("select e from Ebook e where e.status = 'ACTIVE' and (:kw is null or lower(e.titleVi) like lower(concat('%', :kw, '%')) or lower(e.titleEn) like lower(concat('%', :kw, '%')))")
    Page<Ebook> searchActive(@Param("kw") String keyword, Pageable pageable);
}

## 8) Optional: Specifications (tìm kiếm nâng cao Ebook)
`src/main/java/com/ebook/repository/spec/EbookSpecifications.java`
```java
public final class EbookSpecifications {
    private EbookSpecifications() {}

    public static Specification<Ebook> hasStatus(EbookStatus status) {
        return (root, query, cb) -> status == null ? null : cb.equal(root.get("status"), status);
    }

    public static Specification<Ebook> titleContains(String keyword) {
        return (root, query, cb) -> {
            if (keyword == null || keyword.isBlank()) return null;
            String kw = "%" + keyword.toLowerCase() + "%";
            return cb.or(
                cb.like(cb.lower(root.get("titleVi")), kw),
                cb.like(cb.lower(root.get("titleEn")), kw)
            );
        };
    }
}
```

Cách dùng:
```java
var spec = Specification.where(EbookSpecifications.hasStatus(EbookStatus.ACTIVE))
        .and(EbookSpecifications.titleContains(keyword));
Page<Ebook> page = ebookRepository.findAll(spec, PageRequest.of(page, size));
```
