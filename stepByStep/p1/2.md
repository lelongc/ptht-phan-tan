# P1.2 Database Design (Local Docker)

Mục tiêu: chạy MySQL + Redis bằng Docker, tạo schema và seed dữ liệu demo.

## 1) Docker Compose (mysql + redis)
Tạo `docker-compose.yml` ở repo gốc:
```yaml
version: '3.8'
services:
  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: root123
      MYSQL_DATABASE: ebook_store
    ports:
      - "3306:3306"
    volumes:
      - mysql_data:/var/lib/mysql
    healthcheck:
      test: ["CMD", "mysqladmin", "ping", "-proot123"]
      interval: 10s
      timeout: 5s
      retries: 5

  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"
    volumes:
      - redis_data:/data
    command: ["redis-server", "--appendonly", "yes"]

volumes:
  mysql_data:
  redis_data:
```

Chạy:
```bash
docker compose up -d
```

## 2) Schema SQL (database/schema.sql)
```sql
CREATE TABLE IF NOT EXISTS users (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  email VARCHAR(255) NOT NULL UNIQUE,
  name VARCHAR(255),
  phone VARCHAR(50),
  total_orders INT DEFAULT 0,
  total_spent DECIMAL(12,2) DEFAULT 0,
  status VARCHAR(20) NOT NULL DEFAULT 'ACTIVE',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  INDEX idx_user_email (email)
);

CREATE TABLE IF NOT EXISTS ebooks (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  title_vi VARCHAR(255) NOT NULL,
  title_en VARCHAR(255) NOT NULL,
  author_vi VARCHAR(255),
  author_en VARCHAR(255),
  description_vi TEXT,
  description_en TEXT,
  price DECIMAL(10,2) NOT NULL,
  cover_url VARCHAR(255),
  s3_key VARCHAR(255) NOT NULL,
  file_size_mb DECIMAL(10,2),
  page_count INT,
  category VARCHAR(100),
  status VARCHAR(20) NOT NULL DEFAULT 'ACTIVE',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  INDEX idx_title_vi (title_vi),
  INDEX idx_title_en (title_en)
);

CREATE TABLE IF NOT EXISTS orders (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id BIGINT NOT NULL,
  ebook_id BIGINT NOT NULL,
  amount DECIMAL(10,2) NOT NULL,
  status VARCHAR(20) NOT NULL,
  payment_method VARCHAR(20),
  transaction_id VARCHAR(255),
  secret_code VARCHAR(64) NOT NULL UNIQUE,
  payer_email VARCHAR(255),
  payer_name VARCHAR(255),
  paid_at TIMESTAMP NULL,
  expires_at TIMESTAMP NULL,
  download_expires_at TIMESTAMP NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  FOREIGN KEY (user_id) REFERENCES users(id),
  FOREIGN KEY (ebook_id) REFERENCES ebooks(id),
  INDEX idx_order_status (status),
  INDEX idx_order_secret (secret_code)
);

CREATE TABLE IF NOT EXISTS download_tokens (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  order_id BIGINT NOT NULL,
  token VARCHAR(128) NOT NULL UNIQUE,
  expires_at TIMESTAMP NOT NULL,
  used_count INT DEFAULT 0,
  max_uses INT DEFAULT 5,
  last_used_at TIMESTAMP NULL,
  last_used_ip VARCHAR(64),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  FOREIGN KEY (order_id) REFERENCES orders(id),
  INDEX idx_token_expires (expires_at),
  INDEX idx_token_value (token)
);

CREATE TABLE IF NOT EXISTS webhook_logs (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  provider VARCHAR(50),
  order_id BIGINT,
  event_type VARCHAR(100),
  payload JSON,
  status_code INT,
  processed BOOLEAN DEFAULT FALSE,
  error_message TEXT,
  received_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  processed_at TIMESTAMP NULL,
  INDEX idx_webhook_provider (provider)
);
```

## 4) Apply schema + seed
```bash
docker compose exec -T mysql sh -c "mysql -uroot -proot123 ebook_store < /database/schema.sql"
docker compose exec -T mysql sh -c "mysql -uroot -proot123 ebook_store < /database/seed.sql"
```
(Lưu ý mount folder `database/` vào container hoặc chạy `mysql` từ host với `-h 127.0.0.1`).

## 5) Kiểm tra
```bash
docker compose ps
mysql -h127.0.0.1 -P3306 -uroot -proot123 -e "SHOW TABLES;" ebook_store
```
