# P1.3.1 Khởi tạo Spring Boot project

Mục tiêu: tạo project Spring Boot 3, cấu hình Maven, application.properties kết nối MySQL/Redis và i18n.

## 1) Tạo project (Spring Initializr)
- Group: `com.ebook`
- Artifact: `ebook-store`
- Java: 17
- Dependencies: Spring Web, Spring Data JPA, Spring Security, Validation, Thymeleaf, Spring Cache, Spring Data Redis, MySQL Driver, Lombok, Spring Boot Actuator

Tải về và giải nén vào repo (hoặc dùng `curl`/`wget` từ Initializr).

## 2) pom.xml (thêm các lib cần dùng)
- PayPal SDK (rest-api-sdk 1.14.x)
- AWS SDK v2: s3, ses
- JWT: `jjwt-api`, `jjwt-impl`, `jjwt-jackson`
- Flyway (optional) nếu muốn migration
- Dev tools: `spring-boot-devtools`

## 3) Cấu trúc thư mục tối thiểu

## 4) application.properties (local)
```properties
spring.application.name=ebook-store
server.port=8080

# MySQL
spring.datasource.url=jdbc:mysql://localhost:3306/ebook_store
spring.datasource.username=root
spring.datasource.password=root123
spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=false
spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.MySQL8Dialect

# Redis
spring.redis.host=localhost
spring.redis.port=6379
spring.cache.type=redis
spring.data.redis.repositories.enabled=false

# Thymeleaf
spring.thymeleaf.cache=false

# I18n
spring.messages.basename=i18n/messages
spring.messages.encoding=UTF-8
spring.messages.fallback-to-system-locale=false
spring.web.locale=vi
spring.web.locale-resolver=cookie

# Actuator
management.endpoints.web.exposure.include=health,info
management.endpoint.health.probes.enabled=true

# PayPal (sandbox)
paypal.client-id=${PAYPAL_CLIENT_ID}
paypal.client-secret=${PAYPAL_CLIENT_SECRET}
paypal.mode=sandbox

# VietQR (QR động qua img.vietqr.io, không cần API key)
payment.vietqr.bank-code=vietinbank
payment.vietqr.account-number=113366668888
payment.vietqr.account-name=Quy Vac Xin Covid
# Mẫu URL: https://img.vietqr.io/image/{bank}-{account}-compact2.jpg?amount={amount}&addInfo={info}&accountName={name}

# AWS
aws.s3.bucket-name=my-ebook-store
aws.s3.region=ap-southeast-1
aws.s3.access-key=${AWS_ACCESS_KEY}
aws.s3.secret-key=${AWS_SECRET_KEY}
aws.ses.from-email=noreply@yourdomain.com
```

## 5) Main class
```java
@SpringBootApplication
@EnableCaching
@EnableScheduling
public class EbookStoreApplication {
    public static void main(String[] args) {
        SpringApplication.run(EbookStoreApplication.class, args);
    }
}
```

## 6) Kiểm tra build
```bash
mvn clean compile
```
